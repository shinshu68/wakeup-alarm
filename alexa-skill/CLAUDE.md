# alexa-skill

wakeup-alarm の Alexa カスタムスキル (Alexa-hosted)。定型アクション「アレクサ、おはよう」から起動され、FCM でアプリに当日のオフを依頼し、Firestore に書かれた結果を読み上げる。仕様はリポジトリルートの docs/alexa-integration.md を参照する。

## 技術スタック

- Node.js
- Alexa-hosted スキル (開発ステージのまま使い、認定・公開はしない)
- ASK SDK for Node.js
- Firebase Admin SDK：FCM の送信と Firestore の読み取り (M8 で導入)

## 動作確認

- **自動テスト**：LaunchRequest の応答、読み上げの各パターン (成功・0件・応答なし・送信失敗) と、待つ時間が Alexa の応答の制限時間を超えないことを確かめる。Firestore と FCM はモックにし、外部にはアクセスしない
- **開発者コンソールのテスト画面・Echo Dot**：ユーザーに頼む。Claude は Amazon のアカウントに入れないため

使わない手段：

- 本番の Firebase プロジェクトに対するテストは、自動テストでは行わない

ユーザーに確認を頼むとき：

1. Claude が `alexa-skill/` の変更を用意し、決めた手順でのデプロイ方法を示す
2. ユーザーがデプロイし、開発者コンソールのテスト画面か Echo Dot で、示された呼びかけを行う
3. Claude は、確かめてほしい点 (例：読み上げの文、アプリ側でオフになった件数、Pixel 6a の Wi-Fi を切ったときの読み上げ) を箇条書きで示す

## このパッケージ固有のルール

- スキルの応答には約8秒の制限があるため、結果を待つのは6秒程度にする
- Firebase のサービスアカウントの鍵は環境変数から読み込み、コードやリポジトリに含めない
- 定型アクションからはスキルの起動 (LaunchRequest) だけを使う。カスタムタスクは使わない (理由は docs/alexa-integration.md)
